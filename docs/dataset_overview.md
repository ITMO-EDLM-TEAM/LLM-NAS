# Описание датасета ETT-small (Electricity Transformer Dataset)

## 1. Общая информация

**Название:** Electricity Transformer Dataset — поднабор **ETT-small**  
**Область применения:** анализ и прогнозирование временных рядов в энергетике  
**Период наблюдений:** с июля 2016 по июль 2018 (~2 года)  
**Гранулярность данных:**

- вариант `m` — данные с интервалом 15 минут (обозначен как *m* в оригинальном описании);
- вариант `h` — агрегированные почасовые данные (обозначен как *h*).

Датасет содержит измерения с 2 электротрансформаторных подстанций в одном из регионов Китая. Для каждой подстанции
доступны два варианта частоты измерений:

- `ETT-small-m1.csv`, `ETT-small-m2.csv` — 15-минутные данные;
- `ETT-small-h1.csv`, `ETT-small-h2.csv` — почасовые данные.

Каждый из наборов содержит приблизительно:

- `2 года × 365 дней × 24 часа × 4 измерения в час ≈ 70 080` записей.

Данные подготовлены для задач **долгосрочного прогнозирования временных рядов (long sequence time-series forecasting)**.

---

## 2. Структура и поля датасета

Во всех файлах ETT-small используется формат `.csv` с заголовком. Поля:

`date, HUFL, HULL, MUFL, MULL, LUFL, LULL, OT`

| Поле   | Тип (логический) | Описание                                                                         |
|--------|------------------|----------------------------------------------------------------------------------|
| `date` | datetime         | Дата и время записи наблюдения.                                                  |
| `HUFL` | float            | High Useful Load — нагрузка высокого уровня, полезная составляющая.              |
| `HULL` | float            | High Useless Load — нагрузка высокого уровня, неполезная (паразитная/потери).    |
| `MUFL` | float            | Middle Useful Load — нагрузка среднего уровня, полезная составляющая.            |
| `MULL` | float            | Middle Useless Load — нагрузка среднего уровня, неполезная составляющая.         |
| `LUFL` | float            | Low Useful Load — нагрузка низкого уровня, полезная составляющая.                |
| `LULL` | float            | Low Useless Load — нагрузка низкого уровня, неполезная составляющая.             |
| `OT`   | float            | Oil Temperature — температура масла трансформатора, целевая переменная (target). |

Все признаки, кроме `date`, представляют собой числовые временные ряды.

## 3. Целевая переменная и постановка задачи

### 3.1. Что нужно предсказывать

Основная целевая переменная датасета **ETT-small**:

- **`OT` (Oil Temperature)** — температура масла в электротрансформаторе.

Именно `OT` используется как **основной таргет** при обучении моделей прогнозирования.

При желании датасет также позволяет ставить многомерные задачи (совместное предсказание `OT` и нагрузок `HUFL`–`LULL`),
но базовый и наиболее распространённый сценарий — **прогнозирование будущих значений `OT`**.

### 3.2. Типы задач, для которых предназначен датасет

Датасет используется в задачах:

1. **Прогнозирование временных рядов (Time-Series Forecasting)**
    - Вход: история многомерного временного ряда (`OT`, `HUFL`, `HULL`, `MUFL`, `MULL`, `LUFL`, `LULL`) за некоторый
      прошлый интервал времени.
    - Выход: будущие значения `OT` (и, опционально, других признаков) на заданном горизонте.

2. **Долгосрочное прогнозирование (Long Sequence Forecasting)**
    - Используются длинные входные последовательности (сотни и тысячи временных шагов) и длинный горизонт прогноза.
    - Датасет специально применялся для оценки моделей типа Transformer/Informer, способных обрабатывать длинные
      последовательности.

3. **Многомерное прогнозирование (Multivariate Time-Series Forecasting)**
    - Использование нескольких входных признаков нагрузки (`HUFL`–`LULL`) для улучшения прогноза `OT`.
    - Исследование влияния периодических и сезонных паттернов нагрузки на температуру масла.

4. **Прикладная задача в энергетике**
    - Оценка состояния трансформатора по температуре масла.
    - Анализ экстремальной/пикової нагрузки и её влияния на ресурс оборудования.
    - Потенциальное использование прогноза `OT` для предотвращения перегрузок и оптимизации эксплуатации.

Пример формулировки задачи:

> По истории значений `date, HUFL, HULL, MUFL, MULL, LUFL, LULL, OT` за последние *L* шагов времени предсказать
> последовательность будущих значений `OT` на следующие *T* шагов.

## 4. Особенности временных рядов

Датасет сочетает:

- краткосрочные периодические паттерны (суточные циклы нагрузки, локальная автокорреляция `OT`);
- долгосрочные периодические паттерны (недельные и сезонные колебания);
- долгосрочный тренд;
- нерегулярные аномалии (изменения нагрузки, погодные факторы, эксплуатационные режимы).

В оригинальном репозитории визуализированы:

- общий ход целевой переменной `OT` за весь период наблюдения;
- автокорреляционные функции для всех признаков, демонстрирующие:
    - суточный паттерн (период ~24 часа);
    - недельный паттерн (период ~7 дней);
    - локальную гладкость и инерционность `OT`.

Эти свойства делают ETT-small удобным бенчмарком для:

- проверки способности модели захватывать как локальные, так и долгосрочные зависимости;
- тестирования архитектур, ориентированных на длинные последовательности (Informer, Transformer, и др.).

## 5. Формат файлов и использование

### 5.1. Формат хранения

- Формат: `.csv`
- Кодировка: как правило, UTF-8 (заголовки и данные в ASCII).
- Разделитель: запятая (`,`).
- Первая строка содержит заголовки:

  `date,HUFL,HULL,MUFL,MULL,LUFL,LULL,OT`

### 5.2. Типичные шаги предобработки

При работе с датасетом обычно делают:

1. Преобразование `date` в тип datetime и сортировку по времени (на случай, если порядок строк изменён).
2. Нормализацию или стандартизацию числовых признаков (`HUFL`–`LULL`, `OT`).
3. Разбиение на обучающую/валидационную/тестовую выборки по времени (например, первые ~70% — обучение, далее ~10–15% —
   валидация, оставшееся — тест).
4. Формирование скользящих окон:
    - окно входа длиной `L`;
    - окно прогноза длиной `T`.

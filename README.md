# Постановка задачи

Автоматический поиск архитектуры под простую задачу с помощью LLM - написание агента.

Разработка автоматического поиска архитектур на основе LLM для задачи форкастинга, TIME-Series, метрика MSE. Датасеты
ETH1, ETH2 (https://github.com/zhouhaoyi/ETDataset).

Что ожидается от проекта:

- Цикл обучения одной модели можно взять модель Informer (https://github.com/zhouhaoyi/Informer2020). Цикл обучения
  выдает финальую метрку и включает перебор параметров.
- Метод оценки и генрации архитектур через LLM. LLM принимает на вход архитектуру модели и текущее качество, выдает
  новую архитектуру модели.

Для это задачи не нужно обучать LLM, можно взять обученную или вызывать через API. Цель проекта собрать пайплайн с
обратной связью, где модель бы предлагала лучшую архитектуру. Сравнить результат с оптимизаций гиперпараметров через
OPTUNA, где изменяемые параметры это размер вектора, число слоев и т.д.
